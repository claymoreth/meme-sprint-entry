A 1024x1024 meme drawn entirely in code with Python and Pillow — no external
images, no copied template. Run `main.py` and it writes `entry.png` into
`MAKEFUN_OUTPUT_DIR` (default `/output`).

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/meme-out python3 main.py
```

Requires Python 3 and Pillow only. Fully deterministic: same input, same PNG.
